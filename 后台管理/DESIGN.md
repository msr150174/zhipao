# DESIGN.md

## 项目与设计画像
智跑校园 · 运营管理后台 —— 校园跑腿业务（取快递/取外卖）的调度指挥台：管订单、管骑手、管钱。数据密集、操作高频，设计服务于「快速定位 + 安全操作」，不为视觉炫技牺牲效率。

## 气质与意象
傍晚的校园跑道 + 驿站调度台。跑道绿的活力作为品牌印记，界面保持调度台式的理性、克制、低噪音：管理员扫一眼就知道哪单超时、哪笔钱待审。

## Design Tokens
### 色彩
- 品牌主色：跑道绿 `#14A152`（Element Plus primary），意象：塑胶跑道旁的草地
- 侧边栏：墨绿纵向渐变 `#0E2A1D → #123726`（傍晚的跑道），菜单激活项为主色胶囊
- 页面背景：`#F4F6F5`（微绿调灰白），卡片纯白
- 警示/加急：活力橙 `#F97316`（urgent 标记、超时提醒、信用分快捷扣减）
- 状态色沿用 Element Plus 语义色（success / warning / danger / info / primary）

### 字体
- 中文：系统栈（PingFang SC / Microsoft YaHei / Noto Sans CJK）
- 数字：`font-variant-numeric: tabular-nums`（金额、统计指标、表格数字等宽对齐）
- 层级：页面标题 18px/600；统计卡片指标 28px/600；表格正文 14px/400

### 圆角与阴影
- 卡片圆角 8px；单层浅阴影，hover 微浮起（translateY(-2px)）
- 标签/徽章圆角 4px

### 动效
- 统一 150–250ms ease-out，只用 transform / opacity；路由切换淡入淡出
- 禁止大幅度位移动画干扰数据阅读

## 布局与响应式
- 顶栏 60px + 侧边栏 200px（可折叠至 64px）+ 内容区 padding 16–20px
- 统计卡片 2 行 4 列（el-row :gutter + span 6）
- 表格页结构：筛选区（卡片顶部）→ 表格 → 右下分页

## 组件规范
- 危险操作（强制取消、冻结、驳回、设置管理员）必须二次确认；需要原因的操作用带输入框的 Dialog 且原因必填
- 所有列表页必须有 v-loading 加载态、空态、分页
- 金额统一 `¥XX.XX` 两位小数；时间字段后端已格式化为字符串直接展示
- 状态一律 el-tag 按语义着色 + 文字，不单独依赖颜色传达状态

## 设计禁忌
- 禁止蓝紫渐变、玻璃拟态、大面积深色卡片（侧边栏除外）
- 禁止替换 Element Plus 组件交互范式（下拉、弹窗、分页行为保持默认）
- 禁止无文字语义的纯颜色状态区分
