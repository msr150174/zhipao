## 二、启动步骤

### 1. 准备环境

| 组件 | 版本 | 说明 |
|---|---|---|
| **JDK** | 17+ | `java -version` 检查 |
| **Maven** | 3.8+ | 或用 IDE 内置 |
| **MySQL** | 8.0+ | 需先建库 |
| **Redis** | 7.0+ | 可选（不启会报错，见下方说明） |

### 2. 建数据库

```sql
CREATE DATABASE zhipao DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

然后执行两个脚本（**注意顺序**）：

```bash
mysql -u root -p zhipao < db/V1__init_schema.sql
mysql -u root -p zhipao < db/V2__atomic_procedures.sql
```

**验证**：

```sql
SHOW TABLES;                    -- 期望 10 张表
SHOW PROCEDURE STATUS;          -- 期望 6 个存储过程
SELECT COUNT(*) FROM station;   -- 期望 7
SELECT COUNT(*) FROM building;  -- 期望 8
```

### 3. 配置连接

**方式 A：环境变量**（推荐）

```bash
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DB=zhipao
MYSQL_USER=root
MYSQL_PASSWORD=你的密码

REDIS_HOST=localhost
REDIS_PORT=6379
```

**方式 B：直接改 `application.yml`**

### 4. 启动

```bash
cd zhipao-server
mvn spring-boot:run
```

**看到这行就算成功**：

```
Tomcat started on port(s): 3000 (http) with context path '/api'
```

## 三、★ 密钥可以全部留空

**未配置任何密钥时，服务照常启动**，各功能走降级：

| 配置项 | 留空后的行为 |
|---|---|
| `WX_APP_ID` / `WX_APP_SECRET` | 微信登录用 `dev_openid_xxx`（code 派生，稳定可复现） |
| `TENCENT_SECRET_ID` 等 | 短信走**开发模式**（验证码打印到日志） |
| `OLLAMA_BASE_URL` | 跳过本地 AI |
| `COZE_API_TOKEN` | 跳过云 AI → 用规则库 |
| `TENCENT_MAP_KEY` | 跳过地理编码（距离显示「测量中」） |
| `JWT_SECRET` | 用开发默认值（**生产必须配置 ≥32 位**） |

**→ 所以你可以先跑起来，密钥后面慢慢补。**

## 四、验证核心闭环

```json
  "msg": "ok",
  "data": {

```

```bash

  -H "Authorization: Bearer <上一步的 token>"
```

**第 1 步：发验证码**

```bash
  -H "Content-Type: application/json" \
```

```bash

  -H "Content-Type: application/json" \
  -d '{"phone":"13800001234","code":"654321"}'
```

## 八、注意事项

### 8.1 Redis 是必需的

`SmsService` 和 `AiService` 都依赖 Redis。
**若未启动 Redis**，启动时会报连接错误。

**临时绕过**（不推荐）：注释掉 `spring-boot-starter-data-redis` 依赖，
但短信和 AI 缓存会失效。

### 8.2 MySQL 的 `ONLY_FULL_GROUP_BY`

MySQL 8 默认开启。本项目 SQL 已避免该问题。

### 8.3 存储过程权限

执行 `V2__atomic_procedures.sql` 需要 `CREATE ROUTINE` 权限。
若用云数据库，可能需要先授权：

```sql
GRANT CREATE ROUTINE, ALTER ROUTINE, EXECUTE ON zhipao.* TO 'your_user'@'%';
```

### 8.4 时区

`application.yml` 里配了 `serverTimezone=Asia/Shanghai`。
若服务器时区不同，需同步调整。
