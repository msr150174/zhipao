**关键转换处理**：
- `bigserial` → `BIGINT AUTO_INCREMENT`
- `numeric(12,2)` → `DECIMAL(12,2)`
- `timestamptz` → `DATETIME(3)`
- `boolean` → `TINYINT(1)`
- `jsonb` → `JSON`
- **部分唯一索引**（`WHERE status=0`）→ **触发器**（MySQL 不支持）

### 2.2 `V2__atomic_procedures.sql`（346 行，6 个存储过程）

| 存储过程 | 作用 | 并发保护 |
|---|---|---|
| `accept_order_atomic` | 接单 | **CAS 条件更新**（防重复接单） |
| `complete_order_atomic` | 确认收货 + 结算 | **`SELECT ... FOR UPDATE`** 行锁 |
| `withdraw_atomic` | 提现 | 行锁 + **幂等键** |
| `evaluate_order_atomic` | 评价 + 信用分 | 唯一索引防重复 |
| `approve_runner_atomic` | 审核通过 | 行锁 + 事务内标记 `is_runner` |
| `reject_runner_atomic` | 审核驳回 | 条件更新 |

**PostgreSQL → MySQL 的关键差异**：
- `RETURNS TABLE` → **`OUT` 参数**
- `RAISE EXCEPTION` → **`SIGNAL SQLSTATE '45000'`**
- 事务用 **`START TRANSACTION` / `COMMIT` / `ROLLBACK`**

### 4.2 关键实现（替代内存 Map）

**原 NestJS 的 `SmsService` 用内存 Map 存验证码** ——
**多实例部署时会失效**（实例 A 发的码，实例 B 验证不了）。

**Java 版改用 Redis**：

```java
@Service
@RequiredArgsConstructor
public class SmsService {

    private final StringRedisTemplate redis;
    private final SmsClient smsClient;

    private static final String CODE_KEY  = "sms:code:";
    private static final String LIMIT_KEY = "sms:limit:";
    private static final String DAILY_KEY = "sms:daily:";

    /** 发送验证码 */
    public SendSmsResult sendCode(String phone) {
        // 频控 1：60 秒
        Boolean canSend = redis.opsForValue()
            .setIfAbsent(LIMIT_KEY + phone, "1", Duration.ofSeconds(60));
        if (Boolean.FALSE.equals(canSend)) {
            Long ttl = redis.getExpire(LIMIT_KEY + phone, TimeUnit.SECONDS);
            throw new BizException("请 " + ttl + " 秒后再试");
        }

        // 频控 2：每日 10 次
        String dailyKey = DAILY_KEY + phone + ":" + LocalDate.now();
        Long count = redis.opsForValue().increment(dailyKey);
        if (count != null && count == 1) {
            redis.expire(dailyKey, Duration.ofHours(24));
        }
        if (count != null && count > 10) {
            throw new BizException("今日验证码次数已达上限");
        }

        // 生成 6 位码
        String code = String.format("%06d", ThreadLocalRandom.current().nextInt(1000000));

        // ★ 存 Redis（5 分钟）
        redis.opsForValue().set(CODE_KEY + phone, code, Duration.ofMinutes(5));

        // 未配置 → 开发模式
        if (!smsClient.isConfigured()) {
            log.warn("【开发模式】手机号 {} 的验证码为 {}", phone, code);
            return new SendSmsResult(true);
        }

        smsClient.send(phone, code);
        return new SendSmsResult(false);
    }

    /** 校验并删除（一次性） */
    public boolean verifyCode(String phone, String code) {
        String key = CODE_KEY + phone;
        String cached = redis.opsForValue().get(key);
        if (cached == null || !cached.equals(code)) {
            return false;
        }
        redis.delete(key);   // ★ 一次性
        return true;
    }
}
```

### 5.3 `AiService` 路由（**核心逻辑**）

```java
@Service
@RequiredArgsConstructor
public class AiService {

    private final OrderService orderService;
    private final CozeAiProvider cozeProvider;
    private final OllamaAiProvider ollamaProvider;
    private final LocalRuleAiProvider localProvider;
    private final StringRedisTemplate redis;

    /** 安全词 → 强制转人工（不交给任何 AI） */
    private static final List<String> SAFETY_WORDS = List.of(
        "退款", "冻结", "封号", "盗刷", "被骗", "安全", "报警", "客服人工"
    );

    public AiAnswer chat(String userId, List<AiMessage> messages) {
        if (CollectionUtils.isEmpty(messages)) {
            throw new BizException("缺少对话内容");
        }

        String text = messages.stream()
            .filter(m -> "user".equals(m.getRole()))
            .reduce((a, b) -> b)                       // 最后一条 user
            .map(AiMessage::getContent)
            .orElse("")
            .trim();

        if (text.isEmpty()) {
            return fallback("请描述您想咨询的问题。");
        }

        // ① 安全词 → 转人工（不交云端，防止数据出境）
        if (SAFETY_WORDS.stream().anyMatch(text::contains)) {
            return AiAnswer.builder()
                .text("这涉及您的资金或账号安全，已为您转接人工客服（工作时间 9:00–21:00）。")
                .provider("guard")
                .degraded(true)
                .build();
        }

        // ② 查订单 → 本地查库（★ 必须走脱敏视图，不交给 AI）
        if (containsAny(text, "查", "订单", "位置", "到哪", "进度", "单号")) {
            return queryMyOrder(userId);
        }

        // ③ 其他 → 走 AI 引擎（本地优先，云兜底）
        return askAi(userId, messages, text);
    }

    /** AI 引擎路由：本地优先 → 云兜底 → 规则兜底 */
    private AiAnswer askAi(String userId, List<AiMessage> messages, String text) {
        // 结果缓存（相同问题 1 小时内复用）
        String cacheKey = "ai:cache:" + DigestUtils.md5Hex(text);
        String cached = redis.opsForValue().get(cacheKey);
        if (cached != null) {
            return AiAnswer.builder().text(cached).provider("cache").build();
        }

        // ① 本地 AI（Ollama）—— 快、免费、数据不出内网
        if (ollamaProvider.isAvailable()) {
            try {
                AiAnswer ans = ollamaProvider.chat(userId, messages);
                if (StringUtils.hasText(ans.getText())) {
                    redis.opsForValue().set(cacheKey, ans.getText(), Duration.ofHours(1));
                    return ans;
                }
            } catch (Exception e) {
                log.warn("本地 AI 失败，降级到云 AI: {}", e.getMessage());
            }
        }

        // ② 云 AI（Coze）
        if (cozeProvider.isAvailable()) {
            try {
                AiAnswer ans = cozeProvider.chat(userId, messages);
                if (StringUtils.hasText(ans.getText())) {
                    redis.opsForValue().set(cacheKey, ans.getText(), Duration.ofHours(1));
                    return ans;
                }
            } catch (Exception e) {
                log.warn("云 AI 失败，降级到规则库: {}", e.getMessage());
            }
        }

        // ③ 规则兜底（保证永远有回答）
        return localProvider.chat(userId, messages);
    }

    /** 查自己的订单（★ 走 toOrderView 脱敏，防越权） */
    private AiAnswer queryMyOrder(String userId) {
        OrderVO vo = orderService.findLatestActive(userId);
        if (vo == null) {
            return AiAnswer.builder()
                .text("您当前没有进行中的订单。如需查看全部订单，请到「我的订单」。")
                .provider("local")
                .showManualEntry(true)
                .build();
        }
        return AiAnswer.builder()
            .text(String.format("您有 1 个进行中的订单：%s %s，送达地址 %s%s。",
                vo.getOrderNo(), statusText(vo.getStatus()),
                vo.getBuildingName(), vo.getRoomNo()))
            .provider("local")
            .showManualEntry(true)
            .orderId(vo.getId())
            .build();
    }
}
```

### 5.4 `OllamaAiProvider`（本地 AI）

```java
@Component
@RequiredArgsConstructor
public class OllamaAiProvider implements AiProvider {

    private final OllamaProperties props;
    private final RestTemplate restTemplate;

    @Override
    public String name() { return "ollama"; }

    @Override
    public boolean isAvailable() {
        return StringUtils.hasText(props.getBaseUrl())
            && StringUtils.hasText(props.getModel());
    }

    @Override
    public AiAnswer chat(String userId, List<AiMessage> messages) {
        // Ollama /api/chat
        Map<String, Object> body = new HashMap<>();
        body.put("model", props.getModel());
        body.put("stream", false);
        body.put("messages", buildMessages(messages));

        String url = props.getBaseUrl() + "/api/chat";
        ResponseEntity<Map> resp = restTemplate.postForEntity(url, body, Map.class);

        String content = extractContent(resp.getBody());

        return AiAnswer.builder()
            .text(content)
            .provider("ollama")
            .degraded(false)
            .build();
    }

    /** 系统提示词：明确边界，防止 AI 泄露敏感信息 */
    private List<Map<String, String>> buildMessages(List<AiMessage> messages) {
        List<Map<String, String>> list = new ArrayList<>();
        list.add(Map.of("role", "system", "content", """
            你是「智跑校园」的客服助手，帮助学生解答校园代取快递/外卖的问题。

            重要规则：
            1. 绝不能透露任何用户的取件码、手机号、身份证号
            2. 涉及退款、封号、被盗等安全问题，引导用户转人工客服
            3. 回答简洁，控制在 100 字以内
            4. 不确定的问题，建议用户查看订单或联系人工客服
            """));
        for (AiMessage m : messages) {
            list.add(Map.of("role", m.getRole(), "content", m.getContent()));
        }
        return list;
    }
}
```

### 5.5 `CozeAiProvider`（云 AI）

```java
@Component
@RequiredArgsConstructor
public class CozeAiProvider implements AiProvider {

    private final CozeProperties props;
    private final RestTemplate restTemplate;

    @Override
    public String name() { return "coze"; }

    @Override
    public boolean isAvailable() {
        return StringUtils.hasText(props.getApiToken())
            && StringUtils.hasText(props.getBotId());
    }

    @Override
    public AiAnswer chat(String userId, List<AiMessage> messages) {
        String url = props.getBaseUrl() + "/v3/chat";

        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.APPLICATION_JSON);
        headers.setBearerAuth(props.getApiToken());

        Map<String, Object> body = Map.of(
            "bot_id", props.getBotId(),
            "user_id", userId,
            "stream", false,
            "additional_messages", toCozeMessages(messages)
        );

        ResponseEntity<Map> resp = restTemplate.exchange(
            url, HttpMethod.POST,
            new HttpEntity<>(body, headers), Map.class);

        String content = extractCozeContent(resp.getBody());

        return AiAnswer.builder()
            .text(content)
            .provider("coze")
            .degraded(false)
            .build();
    }
}
```

### 5.6 `LocalRuleAiProvider`（规则兜底 + 照搬现有）
